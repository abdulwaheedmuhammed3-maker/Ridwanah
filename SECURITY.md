# Security policy

## Scope

Ridwanah is currently a static health-education website. It does not offer accounts, consultations, a backend, or collection of personal health data.

## Reporting a security concern

Please report security concerns privately to the repository owner through GitHub's private vulnerability reporting feature, if enabled for this repository. Do not post exploitable details in a public issue.

If private vulnerability reporting is unavailable, contact the repository owner through GitHub and request a private reporting channel.

## Expectations

- Do not submit sensitive health information.
- Avoid testing against deployed infrastructure without explicit permission.
- The project is not an emergency service and reports may not receive immediate responses.

## Response

Reports will be assessed and prioritised according to severity, impact, reproducibility and the project's current capacity.
