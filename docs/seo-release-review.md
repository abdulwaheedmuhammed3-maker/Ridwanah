# SEO and domain release review

The final domain is not yet selected. Avoid publishing guessed canonical URLs or a sitemap with placeholder hosts.

## Before domain selection
- [x] Every page includes a title and meta description.
- [x] Open Graph title and description metadata are included.
- [x] Document language is set.
- [x] Public crawler access is permitted by the current robots.txt.
- [ ] Confirm title and descriptions are distinctive across all pages.

## After domain selection
- [ ] Configure the production base URL/canonical URLs in one central place.
- [ ] Generate an XML sitemap using the final absolute domain and the public route list.
- [ ] Add the sitemap URL to robots.txt.
- [ ] Verify sitemap URLs, canonical tags and redirects.
- [ ] Configure social sharing imagery and verify its absolute URL.
- [ ] Verify Search Console and indexing status.
- [ ] Ensure review-pending health drafts are not misleadingly indexed as clinically reviewed content; discuss indexing policy with the editorial lead.

Do not use temporary preview URLs as canonical URLs.
